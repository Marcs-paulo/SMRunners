# São Miguel Runners

Site institucional de um grupo de corrida, feito com **HTML, CSS e JavaScript** puros. É uma página única e responsiva, com apresentação do grupo, depoimentos, calendário de corridas e chamada para inscrição.

O JavaScript marca o item ativo do menu e anima a seção do atleta conforme a página é rolada.

## Como abrir

Não precisa instalar nada: abra o `index.html` no navegador. As imagens ficam em `assets/`.
